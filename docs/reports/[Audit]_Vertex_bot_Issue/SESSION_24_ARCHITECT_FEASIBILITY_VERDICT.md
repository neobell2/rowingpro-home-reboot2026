### 1.2 핵심 주장 검증 결과

#### ① "한 줄의 HTML 코드를 복사해서 붙여넣습니다" → ❌ 과장

**실제:** Google은 `<gen-search-widget>` 웹 컴포넌트를 제공하지만:
- 위젯 라이브러리 로드용 별도 `<script>` 태그 필요
- Google Cloud Console에서 도메인 등록 필요
- 인증 설정 필요 (JWT/OAuth 또는 Public Access)
- 위젯 **스타일 커스터마이징 불가** (Google 공식 문서 명시)
- Dialogflow CX Messenger(`<df-messenger>`)는 약 **39줄** 수준의 HTML 코드

**판정:** "한 줄"이 아니라 **최소 2개 코드 스니펫 + 사전 설정** 필요. 기술적 과장.

#### ② "구글 클라우드 콘솔에서 클릭 몇 번으로 설정" → ❌ 과장

**실제 필요 단계:**
1. Google Cloud 프로젝트 생성
2. **신용카드 연결** (결제 계정 필수)
3. Vertex AI API 활성화
4. 데이터 스토어 생성 (region 지정)
5. PDF 파일 업로드 및 인덱싱 (OCR 옵션 설정)
6. Search 앱 생성
7. 위젯 설정 (인증 방식 선택, 도메인 등록)
8. Enterprise Edition 활성화 (생성형 답변 필요 시)

**판정:** 8단계 이상의 설정. Cloud 경험 없는 영세업자가 1일 만에 완료하기 어려움.

#### ③ "코딩 불필요" → ⚠️ 부분적 과장

**사실인 부분:** 기본 챗봇 생성은 Visual Agent Builder(드래그 앤 드롭)로 가능.
**사실이 아닌 부분:** 제안서가 설명하는 전체 파이프라인(리드 수집 → n8n 연동 → 자동 메일 발송)은:
- Webhook 설정 필요
- 데이터 포맷 매핑 필요
- Google Cloud 서비스 계정 인증 설정 필요
- JSON credential 파일 다루기 필요

**판정:** "Low-code"가 정확한 표현. 순수 "노코드"는 아님.

#### ④ "구글 트라이얼 크레딧 약 $300(약 40만원), 초기 구축 0원" → ⚠️ 불완전

**사실:** $300 크레딧은 존재.
**미고지 사항:**
- **90일 기한** 제한 (제안서 미언급)
- 90일 이후 자동 유료 전환
- 초기 구축이 90일을 넘기면 바로 과금

**판정:** 사실이나 중요한 조건을 누락.

#### ⑤ "월간 운영비 약 3만 원 ~ 8만 원" → ❌ 상당히 과소평가

**독립 비용 산출 (일 평균 15건 상담, 월 450건 기준):**

| 비용 항목 | 최소 (낙관적) | 현실적 추정 | 제안서 반영 여부 |
|:--|--:|--:|:--:|
| Vertex AI Search (검색) | $0 (무료 티어) | $5.40 | 포함 |
| Conversational Agents (대화) | $54.00 | $76.50 | 포함 (과소) |
| Agent Engine Runtime (컴퓨팅) | $0 (유휴 가정) | $62.21 | **❌ 누락** |
| n8n (자동화 도구) | $0 (셀프호스팅) | $26.00 | **❌ 누락** |
| 이메일 발송 서비스 | $0 (무료 티어) | $5.00 | **❌ 누락** |
| **월간 합계 (USD)** | **$54** | **$175** | — |
| **월간 합계 (KRW, @1,350)** | **약 73,000원** | **약 236,000원** | 30,000~80,000원 |

**핵심 문제:**
- 제안서는 **3가지 비용 항목을 완전히 누락** (Agent Engine Runtime, n8n 인프라, 이메일 서비스)
- Conversational Agents의 과금 구조를 단순화 (1 상담 ≠ 1 request, 실제로는 10~30 requests 발생)
- 최선의 경우에도 제안서 상한(8만원)에 겨우 도달
- **현실적 비용은 제안서의 2~3배** (월 16만~24만원)

**판정:** 비용 분석에 심각한 오류. 디렉터의 예산 판단을 오도할 수 있음.

#### ⑥ "연간 총비용 약 50만 원 ~ 120만 원" → ❌ 과소평가

**현실적 연간 비용:** 약 **192만 ~ 283만원** (월 16만~24만원 × 12개월)
- 제안서 대비 **약 2~2.4배** 상향
- "영업 직원 연봉의 3%"가 아니라 약 **6.5~9.4%**
- 여전히 전임 직원 대비 저렴하나, 제안서의 수치는 부정확

#### ⑦ "7일 소요" 구축 로드맵 → ⚠️ 낙관적

| 제안서 단계 | 제안서 소요 | 현실적 소요 | 비고 |
|:--|:--:|:--:|:--|

| Vertex AI 설정 | 1일 | 2~3일 | Cloud 경험 없는 영세업자 기준 |

| 프로젝트 정의 불일치 | AI 챗봇은 현재 범위 밖 | ✅ **동의.** 01번 문서에 명시 없음 |
| Phase 우선순위 | Phase 3/4 완료 우선 | ✅ **동의.** 사이트 미완성 상태에서 AI는 무의미 |

### 2.2 부정확하거나 불충분한 분석

#### ① 기술 스택 충돌 판정 — 오류

**서브아키텍트:** "⚠️ 충돌 — Astro(정적) vs. Vertex AI(동적 클라우드)"
**메인 아키텍트:** ✅ **충돌 아님.** 독립 검증 결과:

- 현재 Astro 프로젝트는 **순수 SSG(정적 사이트 생성)** — 프레임워크 하이드레이션 없음
- 이미 외부 CDN 스크립트 사용 중 (Lucide Icons from unpkg)
- 인라인 `<script>` 블록으로 바닐라 JS 사용 중 (Header 모바일 메뉴)
- 프레임워크 통합(React/Vue) 없음 → 충돌 가능성 없음
- **Astro Island Architecture와 외부 위젯 스크립트 충돌 가능성** → 해당 없음 (Islands 미사용)

**결론:** Astro SSG + 외부 JavaScript 위젯은 기술적으로 **완벽히 호환**됩니다. "정적 vs. 동적 충돌"이라는 프레이밍은 부정확합니다. 위젯은 클라이언트 사이드에서 독립 실행되며 Astro 빌드 파이프라인과 무관합니다.

#### ② 비용 분석 — 미검증

**서브아키텍트:** 제안서의 비용 수치(월 3~8만원, 연 50~120만원)를 그대로 인용
**메인 아키텍트:** 독립 검증 결과 **2~3배 과소평가** 확인 (상세: 섹션 1.2 ⑤~⑥)

**서브아키텍트의 결론 "비용 대비 효과: ✅ 우수"는 잘못된 비용 전제에 기반합니다.**

수정된 비용 기준으로도 B2B 1건 계약(200만원+) 대비 ROI는 여전히 긍정적이나, "연 50만원"과 "연 280만원"은 경영 판단에 질적 차이를 만듭니다.

#### ③ 기술 실현성 — 표면적 검토

**서브아키텍트:** "기술적으로 실현 가능 (7일 소요는 낙관적이나, 10~14일이면 안정적)"
**메인 아키텍트:** 소요 일수 판단에는 동의하나, **아래 핵심 기술 이슈를 누락**:

1. **위젯 스타일링 불가** — Google 공식 문서에서 "위젯 스타일 조정 불가능" 명시. 로잉프로의 프리미엄 다크 테마(Deep #05080F 배경, 글라스모피즘)와 Google 기본 위젯의 **시각적 이질감**이 심각할 수 있음. 디자인 시스템 LOCKED 상태에서 이 불일치는 **브랜드 훼손 리스크**.

2. **Z-index 충돌 가능성** — 현재 Header z-50, 모바일 오버레이 z-60. 채팅 위젯은 z-100 이상 필요. 관리는 가능하나 서브아키텍트가 언급하지 않음.

3. **인증 모드 결정 필요** — Public Access vs. JWT 토큰 기반. 각각 장단점이 다르며 아키텍처 설계에 영향.

### 2.3 서브아키텍트 보고서에서 완전히 누락된 관점

#### 누락 1: AI 오답(Hallucination) 리스크 — 심각도 높음

**이 프로젝트의 특성상 가장 위험한 누락입니다.**

- 로잉프로는 **"13년 무사고"**를 핵심 자산으로 삼는 **안전 중심 B2B 서비스** 기업
- AI 챗봇이 잘못된 가격, 안전 정보, 프로그램 내용을 답변할 경우:
  - 계약 분쟁 발생 가능
  - "13년 무사고" 브랜드 신뢰 훼손
  - B2B 고객사(기업 인사/총무 담당자)의 의사결정 오도
- Vertex AI Search는 학습 데이터 기반 "생성형 답변"을 제공 — **환각(hallucination) 가능성 내재**
- 영세업자 특성상 AI 답변 품질 모니터링 인력 부재

**필요 대응:**
- AI 답변에 "이 답변은 AI가 생성한 참고 정보입니다" 면책 문구 필수
- 가격/안전 관련 답변은 AI 금지 영역으로 설정 필요
- 정기적 답변 품질 검수 체계 필요 (누가 할 것인가?)

#### 누락 2: 대안 솔루션 비교 — 완전히 부재

제안서는 Vertex AI만 제시하고, 서브아키텍트도 대안을 검토하지 않았습니다.

| 솔루션 | 월 비용 | 난이도 | 한국어 | 위젯 스타일링 | 비고 |
|:--|:--|:--:|:--:|:--:|:--|
| **Vertex AI Agent Builder** | 16만~24만원 | 높음 | ✅ | ❌ | 제안서 솔루션 |
| **Intercom** (Fin AI) | $39~/월 | 낮음 | ✅ | ✅ | SaaS, 즉시 사용 |
| **Tidio** (Lyro AI) | $29~/월 | 낮음 | ⚠️ | ✅ | 소규모 비즈니스 특화 |
| **채널톡** (Korean) | 무료~7만원/월 | 낮음 | ✅ | ✅ | 한국 기업, 한국어 네이티브 |
| **카카오 비즈니스 챗봇** | 무료 | 중간 | ✅ | ❌ | 한국 시장 최적화 |
| **ChatGPT Widget** (커스텀) | $20~/월 | 중간 | ✅ | ✅ | GPT API 기반 자체 구축 |
| **단순 FAQ 아코디언** | 0원 | 매우 낮음 | ✅ | ✅ | AI 없이 정적 FAQ |

**메인 아키텍트 의견:** 로잉프로의 규모와 상담 빈도(일 10~20건)를 고려하면, **채널톡 또는 Tidio** 같은 SaaS 솔루션이 Vertex AI보다 비용 효율적이고 운영 부담이 낮을 수 있습니다. 이 비교가 선행되어야 합니다.

#### 누락 3: 벤더 종속(Vendor Lock-in) 리스크

- Vertex AI에 418건 행사 데이터와 비즈니스 로직을 탑재하면 **Google Cloud에 종속**
- 향후 비용 인상, 서비스 변경, 또는 다른 플랫폼 이전 시 **데이터 마이그레이션 비용** 발생
- 영세업자가 클라우드 벤더 협상력을 갖기 어려움
- **대응:** 데이터는 항상 로컬 원본 유지, API 추상화 레이어 검토

#### 누락 4: 운영 지속성 리스크

- "사장님이 직접 설정" — 그러나 설정 후 **유지보수**는 누가 하는가?
  - Vertex AI 모델 업데이트 대응
  - 데이터스토어 갱신 (새 프로그램 추가 시)
  - 에러/장애 대응
  - 비용 모니터링
- 영세업자 특성상 IT 전담 인력 부재
- **이것이 SaaS(채널톡 등) 대비 Vertex AI의 가장 큰 약점**

#### 누락 5: 법적 리스크 상세

서브아키텍트가 "개인정보보호법 검토 필요"라고 언급했지만 분석 부재:

- 418건 행사 데이터에 **담당자 성명/직급/연락처** 포함 가능성 높음
- 이를 Google Cloud에 업로드하면 **개인정보 제3자 제공**에 해당
- 개인정보보호법 제17조: 정보주체 동의 또는 법적 근거 필요
- 과거 데이터의 동의 소급 취득은 **사실상 불가능**
- **대응:** 개인정보 완전 제거(기업명, 인원수, 프로그램 유형만 보존) 후 업로드
- **추가 고려:** AI 챗봇이 수집하는 방문자 이메일도 개인정보 → 수집/이용 동의 UI 필요

#### 누락 6: 성능 영향 분석

- 현재 사이트 빌드 출력: 순수 정적 HTML + 최소 JS
- Vertex AI 위젯 추가 시:
  - 외부 JavaScript 번들 로드 (크기 미확인, 추정 100KB~500KB)
  - Google Cloud API 호출 (레이턴시 추가)
  - 초기 로딩 성능(LCP, FID) 저하 가능
- 현재 **Cloudflare Pages** 배포 — CDN 캐싱과 외부 위젯의 동적 로드 사이 성능 트레이드오프
- **대응:** 위젯 lazy loading(지연 로드) 적용 권장

## 3. 독립적 전문가 평가

### 3.1 제안서 작성자에 대한 평가

**"Vertex AI Solution Expert"라는 서명에 대한 의문:**
- 제안서 작성자의 자격/소속이 불명확
- Google Cloud 공인 파트너인가? 독립 컨설턴트인가?
- 비용 분석의 심각한 과소평가는 **전문성 의문** 또는 **의도적 낙관** 가능성
- "영세업자가 직접 설정 가능"이라는 주장은 **현실과 괴리**
- **판단:** 제안서는 Vertex AI 도입의 **영업 제안서** 성격이 강하며, 객관적 기술 분석서가 아님

### 3.2 이 제안이 로잉프로에 정말 필요한가?

**정직한 분석:**

| 질문 | 답변 |
|:--|:--|
| 로잉프로에 24시간 AI 상담이 필요한가? | **아직 모름.** 현재 사이트가 미완성이므로 실제 문의 트래픽 데이터가 없음 |
| 일 10~20건 상담이 현실적인가? | **불확실.** B2B 기업 사이트의 일반적 문의량은 일 1~5건 수준 |
| AI 챗봇이 B2B 고객 전환에 효과적인가? | **불확실.** B2B 고단가 계약은 대면/전화 상담 비중이 높음 |
| Contact 폼만으로 충분하지 않은가? | **충분할 수 있음.** 사이트 런칭 후 실제 문의 패턴을 파악한 다음 판단해야 함 |

**메인 아키텍트 판단:** 제안서는 **"있으면 좋은 것"**을 **"반드시 필요한 것"**으로 프레이밍하고 있습니다. 현시점에서 Vertex AI 도입의 **필요성 자체가 검증되지 않았습니다.**

### 3.3 내가 모르는 것 (Unknown Unknowns)

투명성을 위해 아키텍트로서 확인하지 못한 사항을 명시합니다:

1. **Vertex AI Conversational Agents의 정확한 한국어 성능** — 한국어 지원은 확인했으나, 조정(rowing) 전문 용어에 대한 이해도는 미확인
2. **Dialogflow CX Messenger 위젯의 정확한 번들 크기** — 성능 영향 정밀 추정 불가
3. **Agent Engine Runtime의 정확한 과금 구조** — 유휴 시 비용 발생 여부 공식 문서 확인 불가 (일부 출처에서 180,000 vCPU-seconds 무료라는 정보가 있으나 미검증)
4. **Generative Agent의 정확한 request 당 비용** — 일부 출처에서 $20/1,000 requests라는 정보가 있으나 공식 확인 불가 (이 경우 비용은 더 증가)
5. **경쟁사(다른 조정/팀빌딩 업체)의 AI 도입 사례** — 벤치마킹 데이터 없음
6. **로잉프로 사장님의 클라우드 기술 수준** — "직접 설정 가능"이라는 제안서 전제의 현실성 판단 불가

## 4. 최종 권고안

### 4.1 Go/No-Go 판단

**현 시점 판정: HOLD (보류)**

**사유:**
1. 현재 웹사이트 미완성 (Phase 3 진행 중) — 사이트 없이 AI 챗봇은 무의미
2. 제안서의 비용 분석이 부정확 — 올바른 예산 수립 불가
3. 실제 문의 트래픽 데이터 부재 — 필요성 자체가 미검증
4. 대안 솔루션 비교 미수행 — Vertex AI가 최선인지 판단 불가
5. 법적 리스크(개인정보) 미해결 — 데이터 정제 선행 필요

### 4.2 권고 실행 순서

```
[현재] Phase 3/4 완료에 집중 (변경 없음)
  ↓
[Phase 4 완료 후] 사이트 런칭 + Contact 폼 실가동
  ↓
[런칭 후 1~2개월] 실제 문의 데이터 수집
  - 월간 문의 건수는?
  - 문의 유형 분포는? (단순 정보 / 견적 요청 / 상담 예약)
  - 응답 소요 시간과 놓치는 문의 비율은?
  ↓
[데이터 기반 판단] AI 도입 필요성 재평가
  - 문의량이 일 5건 이하 → Contact 폼 + 빠른 회신으로 충분
  - 문의량이 일 10건 이상 + 놓치는 비율 높음 → AI 챗봇 검토 타당
  ↓
[도입 결정 시] 대안 솔루션 비교 수행
  - 채널톡 vs. Tidio vs. Intercom vs. Vertex AI vs. 카카오 챗봇
  - 비용, 난이도, 한국어 성능, 유지보수 부담 종합 비교
  ↓
[솔루션 선정 후] PoC (1~2일) → 본격 도입
```

### 4.3 서브아키텍트 권고안과의 차이

| 항목 | 서브아키텍트 | 메인 아키텍트 |
|:--|:--|:--|
| 도입 판정 | 조건부 승인 | **보류** (필요성 미검증) |
| 시기 | Phase 5로 분리 | **데이터 기반 재판단** (Phase 5 확정 불가) |
| 솔루션 | Vertex AI 전제 | **대안 비교 선행** 후 결정 |
| PoC | Phase 5 전 1일 | 솔루션 선정 후 PoC (시기 미정) |
| 비용 기준 | 제안서 수용 (연 50~120만) | **수정 비용** (연 192만~283만) |

### 6.1 독립 검증 수행 범위

| 검증 항목 | 방법 | 신뢰도 |
|:--|:--|:--:|

### 6.2 신뢰도 제한 사항

- Google Cloud 가격 페이지의 일부는 JavaScript 동적 로딩으로 직접 스크래핑 불가 — 2차 출처 의존

- Agent Engine Runtime 무료 티어 적용 범위 미확인
