**작성자:** Operations Architect (Gemini 2.0 Pro)

## Executive Summary

Vertex AI 도입의 가장 큰 리스크는 기술적 구축이 아니라 **"구축 이후의 운영"**입니다. 사장님이 본업(교육 현장)에 집중하는 동안 AI 시스템이 방치되거나 애물단지가 되지 않도록, **사람의 개입을 최소화하는 3대 자동화 파이프라인(Data, Quality, Security)**을 제안합니다.

**핵심 컨셉: "엑셀 관리와 메일 확인만 하세요."**

|:---:|:---|:---|:---|

## 2. 상세 운영 자동화 프로세스

### 2.1 Data Pipeline: "구글 시트로 관리하는 AI 두뇌"
*   **목표:** 사장님에게 익숙한 Google Sheets를 CMS(Content Management System)로 활용하여, 별도의 학습 과정 없이 데이터 갱신.
*   **구성 요소:** Google Sheets + Apps Script + Vertex AI API
*   **워크플로우:**
    1.  **입력:** 사장님이 `[로잉프로_지식베이스.xlsx]` 구글 시트에 새로운 행사 내용 한 줄 추가.
    2.  **트리거:** 시트 내 `[AI 업데이트]` 버튼 클릭.
    3.  **자동화 (Apps Script):**
        *   시트 내용을 정해진 포맷의 PDF로 변환.
        *   Google Cloud Storage(GCS)의 특정 버킷으로 PDF 업로드.
        *   Vertex AI Search의 'Index API'를 호출하여 재학습 요청.
    4.  **완료:** 5분 뒤 챗봇이 새로운 지식을 답변하기 시작.

### 2.2 Quality Pipeline: "매주 월요일 아침 배달되는 성적표"
*   **목표:** 일일이 대화 로그를 뒤져볼 수 없으므로, AI가 '잘 못한' 케이스만 요약해서 보고.
*   **구성 요소:** n8n (Automation) + Gemini Pro (Analysis) + Gmail
*   **워크플로우:**
    1.  **수집:** 지난 일주일간 사용자로부터 `👎 (비추천)` 피드백을 받은 대화 로그 추출.
    2.  **분석:** Gemini Pro에게 해당 로그를 전달하고 분석 요청.
        *   *Prompt:* "사용자가 왜 불만족했는지 원인을 3가지로 요약하고, 사장님이 보강해야 할 데이터가 무엇인지 알려줘."
    3.  **보고:** 분석 결과를 이메일 템플릿에 담아 사장님에게 전송.
        *   *제목:* [로잉프로 AI] 2월 3주차 주간 리포트
        *   *내용:* "이번 주 5건의 불만족이 있었습니다. 주로 '가격표'에 대한 불만이 많으니, 최신 견적서를 업데이트해주세요."

### 2.3 Security Pipeline: "알아서 잠그는 안전장치"
*   **목표:** 사장님이 자는 사이 발생하는 요금 폭탄 원천 차단.
*   **구성 요소:** GCP Billing Budget + Pub/Sub + Cloud Functions
*   **워크플로우 (3중 방어선):**
    *   **1차 (Quota):** 분당 API 호출 수를 60회로 물리적 제한. (DDoS 방어)
    *   **2차 (Budget Alert):** 월 예산($50)의 50%, 80% 도달 시 사장님에게 문자 알림.
    *   **3차 (Circuit Breaker):** 월 예산 100% 소진 시, Cloud Functions가 자동으로 Vertex AI API 키를 **비활성화(Disable)**.
        *   챗봇은 "현재 점검 중입니다. 전화로 문의해주세요."라는 정적 메시지로 자동 전환됨.

## 3. 유지보수 가이드라인 (SOP)

### 상황별 대응 매뉴얼 (For 사장님)

**Q1. 프로그램 가격이 올랐어요.**
> 1. `[로잉프로_지식베이스]` 구글 시트를 엽니다.
> 2. '가격표' 탭에서 숫자를 수정합니다.
> 3. 상단 메뉴의 `[AI 업데이트]` 버튼을 누릅니다. 끝.

**Q2. 챗봇이 이상한 말을 해요.**
> 1. 매주 월요일 오는 이메일 리포트를 확인하세요.
> 2. 리포트에서 "어떤 정보가 부족하다"고 하는지 확인하고, 구글 시트에 해당 내용을 한 줄 추가하세요.

**Q3. 챗봇이 갑자기 멈췄어요.**
> 1. 문자 메시지(GCP Alert)가 왔는지 확인하세요.
> 2. "Budget Exceeded" 문자가 왔다면, 이번 달 예산을 다 쓴 것입니다.
> 3. 급하다면 GCP 콘솔에서 예산을 늘리거나, 다음 달 1일까지 기다리세요 (자동 초기화).

## 4. 결론

본 전략은 **"기술은 복잡하게 구현하되, 사용은 단순하게"**라는 철학을 바탕으로 설계되었습니다. 초기 구축 시 위 3가지 자동화 파이프라인을 함께 세팅한다면, 로잉프로의 Vertex AI는 사장님의 시간을 뺏는 애물단지가 아니라, **스스로 학습하고 보고하는 든든한 영업 파트너**가 될 것입니다.
