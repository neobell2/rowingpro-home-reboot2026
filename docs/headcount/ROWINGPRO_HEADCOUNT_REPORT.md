## 6. 조사 방법론 및 신뢰도

### 데이터 수집 방법
- **도구:** Google Gemini Flash Vision API (이미지 기반 인원 추산)
- **분석 대상:** 2013 ~ 2025년 세션 폴더 내 사진 파일
- **신뢰도 등급:** A (직접 계수) / B (비조끼 팀 수 × 인원 추산) / C (간접 추산)

### 이미지 없는 세션 처리
- 이미지 미보유 세션: **디렉터 지시 기준 인원 적용**
  - 주요 세션 개별 지정 (현대아산아카데미 30명, 조말론 30명, 흥국 양평미리내 90명, ADT캡스 80명, 미디어로그 140명, 파리바게트 100명 등)
  - 나머지 이미지 미확인 세션: **기본 50명** 적용

### 보수적 하한 → 적정 추산 상향 판단 근거
- Gemini 사진 분석은 프레임 내 인원만 계수, 실제 행사 참여자 전체 미반영
- 나이키 위런 등 초대형 공개 이벤트 실제 수천 명 규모 → 보수적으로 집계
- 사진 미보유 세션 다수: 기록·촬영 누락분 포함 시 실제 세션수 약 500건으로 추산
- 평균 참여 인원 × 총 세션수 기준 적정 추산: **약 30,000명**

### 수치 사용 가이드

| 용도 | 권장 수치 |
|:--|:--|
| 내부 보수 집계 (AI 사진 기반) | 약 11,000 ~ 16,000명 / 325건 |
| 적정 추산 (내부 공식 기준) | **약 30,000명 / 약 500건** |
| 홈페이지·대외 홍보 | 디렉터 확정 수치 (적정 추산 이상) |
