## 3) 분류 체계(최소 3타입 고정)
세션을 아래 중 하나로 분류(혼합이면 우세 타입 + 보조 타입 메모):
1. **MEGA(메가 이벤트/전시/부스형)**: 대기열/부스/전시장 전경/장비 다수/운영 인력 다수
2. **GROUP(단체 교육: 기업/학교/기관)**: 강당/연수원/체육관, 팀 구분(조끼/명찰), 일정표/현수막
3. **SMALL(소규모/훈련/개인/내부)**: 인원 적고 장비/공간도 소규모

### 제외(요청 반영)
- 아래 항목은 인원 추산 대상에서 제외:
  - `대회`, `체전`

  - `선수권`, `협회장배`, `시장배`, `탄금호배` 등 “경기/대회성” 명확 항목

## 4) 추정 규칙(“사람 사진” 부족 대응형)
### 4.1 인원 범위 산출(우선순위)
1. **단체샷/진행샷이 충분**: 눈대중 헤드카운트 → `min~max`로 기록(예: 35~45)
2. **장비 세팅 기반**: `장비대수 × 회전수(1~3)`로 범위 추정  
   - 예: 머신 8대, 2~3회전 추정 → 16~24명(팀빌딩이면 30~60로 상향 가능)
3. **운영/전경/대기열 기반**: 이벤트 타입(특히 MEGA) 판정 후 보수적 범위 적용

### 4.3 (추가) 영상/샘플링 편차 방지 규칙
- 사진이 없어서 **동영상 프레임 일부**로 판단할 경우 편차가 커질 수 있으므로, 세션 기록에 아래를 필수로 남긴다:
  - `src=photo|video|mixed`, `sample_n≈N` (가능하면 `coverage=good|partial`)
- `src=video`이고 `sample_n<5` 또는 `coverage=partial`이면:
  - `confidence`는 최대 `C`로 제한하고, `notes=needs_resample` 표기
  - 범위가 과하게 튀면(특히 시리즈 내 2배 이상) 확정하지 말고 재샘플

### 4.4 (추가) 시리즈 상속(반복 세션 정합성)
흥국-양평미리내처럼 “같은 프로그램/같은 장소/연속 회차”는 `series_id`로 묶는다.
- 기준 회차 1개(근거가 가장 좋은 회차)를 먼저 확정한다.
- 동일 `series_id`의 나머지 회차는 기본적으로 기준 범위를 **상속**한다.
- 덮어쓰기는 `confidence`가 A/B이고 “명확한 근거”가 있을 때만 허용한다.

### 4.2 타입별 “기본 범위표”(초기값, 필요시 프로젝트에 맞게 조정)
- MEGA: **800~1500명/일(또는 세션)** *(부스형은 “유동 인원” 특성상 넓게 잡고 보수적으로 합산)*
- GROUP: **30~80명/세션**
- SMALL: **5~20명/세션**

> 주의: 위 범위는 “초기 가정”이며, 샘플링으로 현실값을 확인하면 즉시 업데이트하고 방법론 문서에 버전 기록.

## 5) 신뢰도(품질 들쑥날쑥 대응)
세션마다 아래 중 하나 부여:
- **A(상):** 단체샷/진행샷/명확한 인원 단서 2개 이상
- **B(중):** 장비대수/공간규모 등 간접 단서 2개 이상
- **C(하):** 표지판/전경 위주로 간접 단서 0~1개

## 7) 실행 절차(반복 루프)
1. (준비) 연도 폴더의 세션 목록 확보(폴더명/경로)

4. (요약) N개 처리마다: 누적 세션 수 + 누적 `min 합` / `max 합` + 타입별 개수만 대화에 남김

## 10) 모델 선택 가이드(속도/품질/비용/세션오류 최소화)
### 결론(권장 운영)
- **대량 처리(세션 분류 + 범위 산출 + CSV 1줄):** 빠르고 저렴한 모델(Flash급) 사용
- **룰/범위표 캘리브레이션(초기 20~30세션, 애매 케이스):** 상위 모델(더 강한 추론/일관성)로만 간헐적 사용

### 판단 기준
- **속도:** 세션당 “3~10장 샘플 → 1줄 출력” 반복이므로 Flash급이 유리
- **품질:** 정밀 계수가 아니라 “타입 판정 + 범위 선택”이 핵심이라, 규칙이 고정되면 모델 차이가 줄어듦
- **비용:** 반복 횟수가 많아 단가가 중요(Flash급이 유리)
- **세션오류 최소화:** 모델보다 **워크플로(컨텍스트 절약)**가 결정적
  - 출력은 항상 짧게, CSV로 누적, 대화는 요약만(본 WO의 8항 준수)
