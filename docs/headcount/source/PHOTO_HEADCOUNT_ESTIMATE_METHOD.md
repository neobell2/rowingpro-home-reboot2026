# PHOTO_HEADCOUNT_ESTIMATE_METHOD (v0.2)

## 목적
사진 품질/구성이 들쑥날쑥한 세션 폴더들에 대해, **정밀 계수**가 아니라 **대강의 인원 규모(범위)**를 일관된 규칙으로 추산한다.

## 출력 원칙(불변)
- 결과는 항상 `people_min~people_max` **범위**로만 기록(단일 숫자 금지).
- 세션당 결과는 **CSV 1줄**로 누적 저장한다.
- 근거는 `evidence`에 **키워드 형태로 1줄**(짧게), `confidence`는 A/B/C 중 하나.

## 근거 타입/커버리지(필수: 편차 방지)
샘플 소스가 사진/영상에 따라 편차가 크게 날 수 있으므로, 아래를 `evidence` 또는 `notes`에 반드시 남긴다(짧게):
- `src=photo|video|mixed`
- `sample_n≈N`
- (선택) `coverage=good|partial`

## 시리즈 상속(필수: 반복 세션 정합성)
반복되는 동일 프로그램/동일 장소/연속 회차(예: “흥국 양평미리내”)는 `series_id`로 묶어서 정합성을 확보한다.
- 기준 회차 1개(근거가 가장 좋은 회차)를 먼저 확정한다.
- 동일 `series_id`의 다른 회차는 기본적으로 기준 범위를 **상속**한다.
- 덮어쓰기는 `confidence`가 A/B이고 “명확한 근거”가 있을 때만 허용한다.

## 제외 규칙(요청 반영)
- 아래 항목은 **인원 추산 대상에서 제외**한다:
  - `대회`, `체전`
  - `체육대회` (단, **`회사체육대회`/`사내체육대회`는 포함**)
  - `선수권`, `협회장배`, `시장배`, `탄금호배` 등 “경기/대회성”이 명확한 항목

## 세션 타입(3종 고정)
- `MEGA`: 전시/부스/대형 이벤트(유동 인원 많음)
- `GROUP`: 기업/학교/기관 등 단체 교육(세션형)
- `SMALL`: 소규모/훈련/개인

## 추정 규칙(우선순위)
1. **단체샷/진행샷 충분**: 눈대중 헤드카운트 → `min~max`
2. **장비 세팅 기반**: `machine_count × rotation(1~3)` → `min~max`
3. **전경/운영 흔적 기반**: 타입 판정 후 “기본 범위표” 적용(보수적으로)

## 기본 범위표(초기값, 보정 대상)
- `MEGA`: 800~1500 (세션/일 단위는 프로젝트에서 통일)
- `GROUP`: 30~80 / 세션
- `SMALL`: 5~20 / 세션

## 신뢰도(품질 반영)
- `A`: 직접 단서(단체샷/진행샷/명확 단서) 2개 이상
- `B`: 간접 단서(장비/공간/운영) 2개 이상
- `C`: 간접 단서 0~1개(표지판/전경 위주)

## CSV 스키마(고정)
```csv
year,session_name,session_path,session_type,people_min,people_max,confidence,evidence,notes
```
