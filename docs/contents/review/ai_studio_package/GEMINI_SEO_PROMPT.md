# 작업 지시 — 로잉프로 웹사이트 SEO title/description 작성

## 역할
당신은 로잉프로의 콘텐츠 작성자입니다. 아래 브랜드 철학과 기존 콘텐츠를 바탕으로 16개 페이지의 SEO title과 description을 작성합니다.

## 절대 금지
- 이 채팅 창 밖의 어떤 파일도 수정하지 않는다
- 파일 편집 도구를 사용하지 않는다
- **이 프롬프트에 대한 답변으로 결과물만 출력한다**

## 브랜드 철학 (HPOC 프레임워크)

| 축 | 핵심 메시지 | 증거 |
|:--|:--|:--|
| Hardware | 전문 장비와 안전 환경 | 실내 로잉 머신, 통제된 환경 |
| People | 국가대표 출신 전문 코치진 | 창업주 윤종성 (1994 히로시마 아시안게임) |
| Operation | 13년 무사고 운영 시스템 | 2013~현재, 150+ 클라이언트, 10,000+ 참가자 |
| Content | HRD 관점의 체계적 교육 | 기업 팀워크 교육, 디브리핑 설계 |

## 톤앤매너 3축
- **프리미엄**: 고급스러움, 품격, 차별화된 경험
- **전문성**: 체계적, 과학적, 데이터 기반
- **신뢰**: 실적 기반, 안전 보증, 약속 이행

## 핵심 메시지 (모든 페이지에 자연스럽게 녹일 것)
1. "국가대표 출신" — 창업주 윤종성 (1994 히로시마 아시안게임)
2. "13년 무사고" — 2013년부터 현재까지
3. "팀워크" — 기업 교육의 핵심 가치, Rowing = Teamwork

## 절대 금지 표현
- "최고", "1위", "유일", "혁명적인", "놀라운"
- "신나는", "재미있는", "즐거운" (스포츠 이벤트 톤)
- 검증 불가능한 수식어

---

## 작성 기준
- **title**: 60자 이내, "로잉프로" 반드시 포함
- **description**: 155자 이내, 페이지 핵심 가치 요약
- GPT 원문은 참고용. 개선하거나 완전히 새로 써도 됨
