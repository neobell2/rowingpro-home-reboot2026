# 콘텐츠 리뷰 가이드 (Director용)

본 폴더(`docs/contents/review/`)는 콘텐츠 고도화 단계에서 각 초안을 비교하고 최종안을 확정하기 위한 작업 공간입니다.

## 1. 파일 구성
*   **Original**: 기존에 작성된 기준 콘텐츠 (v1.1)
*   **GEMINI Draft**: 제미나이(Gemini 3.0 Pro)가 작성한 혜택 및 감성 중심 초안
*   **OPUS Draft**: 오퍼스(Claude Opus 4.6)가 작성한 선언적/사실 중심 초안
*   **[파일명]_REVIEW.xls**: 위 3종을 한눈에 비교하고 최종안을 작성할 수 있는 엑셀 파일

## 2. 검토 및 확정 방법 (XLS 사용법)
1.  각 페이지별 `*_REVIEW.xls` 파일을 엑셀(Excel)에서 엽니다.
2.  **Section**별로 3가지 버전을 비교합니다.
3.  최종적으로 사용하고 싶은 문장을 **Director (Final)** 열에 입력합니다.
    *   특정 안을 그대로 사용하거나, 여러 안의 장점을 섞어서 작성하실 수 있습니다.
4.  작업이 완료된 파일을 저장합니다.

## 3. 최종 반영 절차
디렉터님이 **Director (Final)** 열 작성을 완료하신 후 말씀해 주시면, 제가 해당 내용을 바탕으로 `docs/contents/` 루트에 있는 실제 서비스용 파일들을 일괄 갱신하겠습니다.
