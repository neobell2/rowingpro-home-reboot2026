# Programs 페이지 콘텐츠 (v1.0)

**최종 갱신:** 2026-02-15

---

## 1. 페이지 역할 [LOCK]

- Programs는 **전체 프로그램 개요/분류**를 제공한다.
- 상세 커리큘럼/견적/운영 조건은 Service 하위 상세 페이지로 연결한다.

---

## 2. 4대 프로그램 요약 [LOCK]

### 2.1 인도어 프로그램
- 실내 에르고미터 중심 기초 및 팀워크 훈련

### 2.2 아웃도어 프로그램
- 실제 보트 탑승, 수상 실습 중심

### 2.3 체험형 부스 프로그램
- 행사/축제/캠페인용 단기 체험 패키지

### 2.4 MIX 프로그램
- 실내외 병행 순환식 교육

---

## 3. 연결 정책

- Programs CTA는 `/service`로 통일한다.
- 세부 가격/조건을 Programs에서 직접 확정 노출하지 않는다.
