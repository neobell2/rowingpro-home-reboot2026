## 1. Service Hub 카테고리

### 1.1 기업·조직
- HRD 적용형: 신입교육, 조직개발, 리더십
- 비HRD 적용형: 기념행사, 단합대회, 체육행사

### 1.2 학교·청소년
- 인성 교육, 체육 활동, 리더십 캠프

### 1.3 스포츠 이벤트·행사
- 패키지(SIMPLE/CORE/PRO/MASTER) 기반 대규모 체험 운영

### 1.4 클럽·일반
- 정기 레슨, 동호회 활동, 원데이 체험

### 1.5 가족 체험
- 비상품 안내형 운영 (문의 연결 중심)

## 3. 가격/노출 정책

- 기본 원칙: **상담 유도형** (가격 비노출)
- 예외: 스포츠 이벤트 부스형은 패키지 체계로 게시 가능
  - 패키지명 확정: **SIMPLE / CORE / PRO / MASTER**
  - **PRO = 200만원 + VAT** (머신 10대, 강사 2인, 4시간, 서울·경기 기준)
  - SIMPLE/CORE/MASTER 세부 금액 및 구성은 행사 목적/규모에 따라 협의
