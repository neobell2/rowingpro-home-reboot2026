## 1. 핵심 메시지 [LOCK]

### 1.1 왜 조정인가
- 개인 역량만으로는 성과가 완성되지 않는 상황에서, 조정은 팀의 작동 원리를 가장 명확하게 보여주는 훈련 방식이다.

### 1.2 교육으로의 번역 (HPOC 구조)
- **Hardware:** 장비, 공간, 동선, 안전
- **People:** 역할 배치, 코치 개입, 팀 구성
- **Operation:** 세션 흐름, 실행 규칙, 피드백 루프
- **Content:** 시나리오, 과제, 디브리핑 문항
